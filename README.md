# 🔴 포켓몬키우기

내 바탕화면 위에서 살아 움직이는 포켓몬을 키우는 데스크톱 펫 게임입니다.
PyQt6로 만들었고, Windows용 실행 파일(exe) 하나로 바로 즐길 수 있습니다.

![Python](https://img.shields.io/badge/Python-3.12-blue?logo=python&logoColor=white)
![PyQt6](https://img.shields.io/badge/PyQt6-GUI-41CD52?logo=qt&logoColor=white)
![Platform](https://img.shields.io/badge/Platform-Windows-0078D6?logo=windows&logoColor=white)

---

## ✨ 특징

- 바탕화면 위를 걸어 다니고, 점프하고, 드래그해서 옮길 수 있는 픽셀 애니메이션 포켓몬
- **이브이 / 따라큐 / 꼬북이 / 리오르 / 이어롤 / 랄토스** 중에서 시작 포켓몬 선택
- 레벨업 시 진화 (이브이는 8종 이브이션 중 원하는 형태로 선택 진화!)
- 친밀도 · 포만감 · 목숨(하트) 시스템이 있는 **포켓몬 상자**로 여러 마리 동시 관리
- 최대 6마리까지 키우고, 필요 없으면 상자에서 언제든 삭제 가능
- 새로하기 / 이어하기를 선택하는 시작 화면
- 인터넷 연결 없이도 완전히 오프라인으로 동작

---

## 🎮 튜토리얼

### 1. 처음 실행하면

<img alt="start" src="https://img.shields.io/badge/1-시작-FF5252?style=flat-square" /> 게임을 켜면 **새로하기 / 이어하기 / 프로그램 종료** 중 하나를 고르는 시작 화면이 뜹니다.
- **새로하기**: 시작 포켓몬을 새로 고르고 처음부터 시작합니다 (기존 데이터가 있으면 한 번 더 확인합니다).
- **이어하기**: 저장되어 있던 포켓몬을 그대로 불러옵니다. 저장 데이터가 없으면 비활성화되어 있습니다.

시작 포켓몬을 고르고 닉네임을 지어주면, 그 포켓몬이 바로 바탕화면에 나타납니다.

### 2. 포켓몬과 놀아주기

| 동작 | 효과 |
|---|---|
| 왼쪽 클릭 | 하트 이펙트 + 친밀도 소폭 상승 |
| 마우스로 드래그해서 옮기기 | 화면 아래쪽에 놓으면 친밀도 상승, 위쪽에 놓으면 하락 |
| 오른쪽 클릭 | 먹이 주기 — 포만감 회복 + 친밀도 상승 |
| 가만히 두기 | 포켓몬이 알아서 걸어 다니거나, 멈추거나, 가끔 점프합니다 |

친밀도가 100이 되면 레벨이 1 올라가고, 특정 레벨에 도달하면 **진화** 여부를 물어봅니다 (이브이는 진화할 포켓몬을 직접 선택).

### 3. 포만감과 목숨

- 포만감은 시간이 지나면서 서서히 줄어듭니다. 오른쪽 클릭으로 먹이를 주면 채울 수 있어요.
- 포만감이 0이 되면 목숨(하트)이 1개 줄고, 자동으로 포켓몬 상자에 들어갑니다.
- 상자 안에 있는 동안에는 포만감이 자동으로 어느 정도(최대 50)까지 회복됩니다.
- 목숨이 모두 사라지면 그 포켓몬은 상자에서 흐릿하게 표시되며, 삭제 외에는 아무 것도 할 수 없게 됩니다.

### 4. 포켓몬 상자

화면 왼쪽 아래의 **포켓볼 아이콘**을 클릭하면 포켓몬 상자가 열립니다. 여기서 할 수 있는 것:

- **꺼내기 / 집어넣기**: 포켓몬을 바탕화면에 꺼내거나 상자에 도로 넣기 (꺼낼 때 반갑다고 점프 두 번 + 하트!)
- **이름변경**: 닉네임 수정
- **삭제**: 확인창을 한 번 더 거쳐 완전히 삭제 (마지막 한 마리도 삭제 가능)
- **새 포켓몬 추가하기**: 최대 6마리까지 새로 데려오기
- 지금 바탕화면에 나와 있는 포켓몬은 카드가 **분홍색**으로 표시됩니다

## ⬇️ 다운로드 (그냥 플레이만 하고 싶다면)

Python 설치 없이 바로 실행하고 싶다면, [Releases](../../releases) 페이지에서 최신 zip 파일을 받아 압축을 풀고 `.exe` 파일을 실행하세요.

인터넷 연결이 없는 PC에서도 그대로 동작합니다. 저장 데이터는 exe 파일 옆에 `Pokemon_saves` 폴더로 자동 생성됩니다.

## 🛠️ 소스코드로 직접 실행하기

```bash
git clone https://github.com/it-mnm/pokemon-desktop-pet.git
cd pokemon-desktop-pet
pip install -r requirements.txt
python main.py
```

Windows에서는 `run.bat`을 더블클릭해도 됩니다.

직접 exe로 빌드하는 방법은 [BUILD_GUIDE_KR.md](BUILD_GUIDE_KR.md)를 참고하세요.

## 📁 프로젝트 구조

```
├── main.py            # 진입점, 포켓몬 상자/포켓볼 버튼, 저장 데이터 관리
├── pet.py              # 바탕화면 포켓몬 위젯 (이동/점프/진화/포만감 로직)
├── dialogs.py           # 시작화면, 포켓몬 추가/상자 UI, 공용 확인창
├── utils.py             # 픽셀 폰트 로드, 에셋 경로, 스프라이트 크기 계산
├── save_manager.py      # JSON 저장/불러오기
├── assets/              # 포켓몬 GIF, 픽셀 폰트, 아이콘
└── requirements.txt
```
